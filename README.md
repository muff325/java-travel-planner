Java Travel Planner

Project Goal:
The goal of this project is to create a Java program that helps users organize trips, plan activities, and track estimated travel expenses.

Features:
- Create trips with destinations and travel dates.
- Add activities to each trip.
- Record estimated activity costs.
- Calculate total trip expenses.
- Save and load trip information using file storage.

Future Plans:
- Add weather forecasts for destinations.
- Generate suggested travel itineraries.
- Compare expenses across multiple trips.

Tech Stack:
- Language: Java
- IDE: IntelliJ IDEA
- Libraries: ArrayList, java.io, java.time, Scanner.
- Data Storage: CSV or text files.
- Version Control: Git and GitHub.

Project Structure:
- src/ – Contains Java source code.
- docs/ – Contains the design document, Eisenhower Matrix, and system diagram.

How to Run:
- Clone or download the repository.
- Open the project in IntelliJ IDEA.
- Run Main.java.
